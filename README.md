# chaseur-trade
The objective of this repository is to serve as both a personal learning exercise as well as a template on how to interact with the market and build applications for trading.

# Project Roadmap

## Phase 1: Market Data Ingestion
[] Be able to ingest Coinbase order book market data and store it in a database.

## Phase 2: Data Quality, Replay, and Analitics
[] Be able to replay market data from a database and compute metrics on it.

## Phase 3: Backtesting and Strategy Design
[] Build a modular platform that allows for backtesting of trading strategies.

## Phase 4: Risk Engine and Live Trading
[] Enable safe live trading of designed strategies.
